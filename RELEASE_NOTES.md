# Reverse Image Search Tools 2.0

- The toolbar opens a shared search workspace. Supported desktop browsers show
  it in their native sidebars.
- Choose, paste, or drop an image, enter a direct image link, or capture part
  of the active page in a supported sidebar.
- Fresh installations enable and select Google Lens, Bing, Yandex, and TinEye.
  Six more providers are available through Add engines in Settings.
- Sogou uses its current uploader for both files and image links.
- The Chrome right-click menu groups Open image, All search engines, and
  individual engines. Fresh installations look for nearby images and alternate
  sizes of the clicked image. Updates use the preferences saved in the existing
  profile.
